WildCat 是什么

训练流程参考 Nuke CopyCat，参数、单位、输出文件命名与 CopyCat 一致；训练出的 TorchScript 模型（.pt）经 Nuke 自带的 CatFileCreator 节点转换为 .cat 后，即可在 Inference 节点使用。 在相同设置下训练结果与 Nuke 17 CopyCat 处于同一水平（20 万 epoch 长训练逐阶段 loss 吻合）。

Batch Size：Auto / ManualAuto (8) / 手动Auto = 8，显存不足时自动减小；不能大于帧数

Use Multi-Resolution TrainingMulti-Resolution三段等长：1/4 → 1/2 → 1/1
Checkpoint Interval（1000 步）Checkpoint Interval每次在任务目录保存 Training_日期_时间.<step>.pt（TorchScript，用 CatFileCreator 转为 .cat）
Contact Sheet Interval（100 步）Contact Sheet Interval保存 Training_日期_时间.<step>.png（输入 | Ground Truth | 输出）并刷新整帧预览

加速选项与显存

加速选项（默认全部开启）：训练算法与 CopyCat 相同，只改执行方式——数据常驻显存、整步 CUDA Graph、融合 Adam、NHWC、cuDNN 自动选算法、异步写盘、预览在副卡推理。 面板右上角的总开关可一键全部开启或关闭；全部关闭时为不做任何执行优化的朴素实现，只用于对照验证，速度约为开启时的 1/2~1/3。

显存：16 / 24 / 32 GB 使用同一套自动策略。数据集不超过空闲显存 60% 时常驻显存，否则自动改为内存预取（速度损失 0~4%）。 机器有第二张 GPU 且空闲时，预览、验证与 contact sheet 在副卡上异步推理，主卡只做训练。
